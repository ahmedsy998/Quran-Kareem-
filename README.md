# صانع فيديوهات القرآن (Quran Video Maker)

تطبيق أندرويد أصلي مكتوب بلغة **Kotlin** و **Jetpack Compose (Material 3)** لصناعة وتصميم فيديوهات تلاوة القرآن الكريم بجودة عالية لمنصات التواصل الاجتماعي، مع واجهة عربية كاملة (RTL) ومزامنة دقيقة آيةً بآية.

## المزايا الرئيسية
- **مزامنة آية بآية بدقة عالية:** تشغيل التلاوة كملفات صوتية لكل آية منفردة (أو توقيتات الآيات المعتمدة) بحيث يتطابق النص المعروض في سطر واحد مع الآية التي يتلوها القارئ لحظياً في المعاينة وفي الفيديو المُصدّر.
- **المصحف العثماني الكامل (114 سورة - 6,236 آية):** مدمج بالكامل ويعمل دون اتصال بالإنترنت مع معالجة البسملة التلقائية.
- **24+ قارئاً من مشاهير القراء:** دعم البحث والمفضلة والتحميل والتخزين المؤقت للتلاوات للعمل لاحقاً دون إنترنت، مع دعم جلب قائمة القراء من MP3Quran API.
- **الخطوط العربية والقرآنية:** خطوط مدمجة (أميري قرآن، شهرزاد الجديد، خط حفص العثماني، القاهرة، تجوال، المراعي، نوتو كوفي العربي، آي بي إم بلكس العربي).
- **تلوين التشكيل المستقل:** فصل وتلوين علامات التشكيل (`U+064B–U+0652`, `U+0670`, `U+06D6–U+06ED`) بلون وحجم مستقل في المعاينة والتصدير.
- **خلفيات صور وفيديو:** مكتبة مدمجة من الخلفيات الإسلامية والطبيعية بالإضافة لاختيار صورة أو فيديو من الهاتف، مع تحكم بالسطوع/التعتيم والضبابية والتكرار.
- **المقاسات الاحترافية:** دعم `9:16` و `16:9` و `1:1` و `4:5` مع معاينة فورية وتصدير MP4 بدقة `720p` أو `1080p` عبر **Jetpack Media3 Transformer**.
- **تخصيص كامل لكل عنصر:** العنوان التلقائي للسورة (أعلى)، اسم القارئ (أسفل)، والعلامة المائية الاختيارية للمستخدم، مع الحفظ التلقائي الفوري في **Room + DataStore** ودعم تعدد المشاريع وطابور المعالجة المتعددة (Batch Queue).

## البناء عبر GitHub Actions
يحتوي المستودع على ملف `.github/workflows/build-apk.yml` لبناء ملف APK تلقائياً وإرفاقه باسم `QuranVideoMaker-APK`.
